# VoiceScribe — Презентация проекта

## Что такое VoiceScribe?

**VoiceScribe** — это десктопное приложение для Windows, которое записывает и транскрибирует аудио с встреч, созвонов и любых других источников звука. Приложение одновременно захватывает микрофон и системный звук (Teams, Discord, Zoom и т.д.), автоматически определяет спикеров по источнику аудио и распознаёт речь на нескольких языках.

Главный принцип: **все данные остаются на вашем компьютере**. Никакие аудиозаписи и транскрипции не отправляются в облако.

## Стек технологий

| Компонент | Технология |
|-----------|-----------|
| **Бэкенд (ядро)** | Python 3.11+ |
| **GUI фреймворк** | Electron 28 |
| **Фронтенд** | React 19 + TypeScript + Vite 7 |
| **State management** | Zustand |
| **Распознавание речи** | faster-whisper (CTranslate2) |
| **Захват системного звука** | PyAudioWPatch (WASAPI Loopback) |
| **Захват микрофона** | sounddevice |
| **Диаризация спикеров** | pyannote-audio 3.1 |
| **Голосовые отпечатки** | speechbrain ECAPA-TDNN |
| **База данных** | SQLite (aiosqlite, WAL mode) |
| **IPC** | JSON-RPC 2.0 over stdio |
| **Сборка** | electron-builder (portable .exe) |

## Как это работает

### Архитектура: Record -> Transcribe

```
1. ЗАПИСЬ                    2. ТРАНСКРИПЦИЯ              3. РЕЗУЛЬТАТ

 Микрофон ----+              Аудио (WAV)                  Протокол встречи
              |                  |                             |
              v                  v                             v
         [Mixer 50/50]  ->  [faster-whisper]  ->  [SQLite]  ->  [Экспорт]
              ^              (batch, small,        хранение     txt/md/srt/json
              |               int8, greedy)
 Системный ---+                  |
 звук                            v
 (WASAPI                  [pyannote + ECAPA]
  Loopback)               диаризация + ID
```

### Пошаговый процесс

1. **Запись** — пользователь выбирает микрофон и системное аудио устройство, нажимает "Record"
2. **Dual Capture** — параллельно захватывается звук с микрофона и WASAPI Loopback
3. **Остановка** — при нажатии "Stop" потоки микшируются (50/50) в единый WAV
4. **Транскрипция** — faster-whisper обрабатывает аудио batch-режимом с автоопределением языка по 30-секундным чанкам
5. **Идентификация спикеров** — pyannote разделяет речь по спикерам, ECAPA-TDNN сравнивает с сохранёнными профилями
6. **Сохранение** — результат записывается в SQLite с таймстемпами, метками спикеров и confidence
7. **Экспорт** — пользователь может экспортировать в txt, markdown, srt (субтитры) или json

## Ключевые возможности

### Dual Audio Capture (микрофон + системный звук)
- Одновременный захват из двух источников
- Раздельные VU-метры для контроля уровня
- Микширование с равным весом (50/50)

### Мультиязычная транскрипция
- Автоопределение языка по 30-секундным чанкам
- Поддержка переключения языков внутри одной записи (например, русский -> английский)
- Языки: Auto-detect, English, Russian (Русский), Ukrainian (Українська), Spanish (Espanol)

### Идентификация спикеров
- По источнику: микрофон = вы, системный звук = собеседники
- По голосовому отпечатку: speechbrain ECAPA-TDNN (192-dim embeddings)
- Обучение на 2-3 образцах голоса
- Cosine similarity с порогом 0.70

### Полностью локальная работа
- Все модели ML загружаются один раз и работают офлайн
- Данные никогда не покидают компьютер
- Не требуется интернет после установки

### Экспорт и архив
- Форматы: txt, markdown, srt (субтитры), json
- История всех встреч с поиском
- Детальный просмотр каждой встречи с таймстемпами

### Десктопное приложение
- Custom frameless window (кастомный title bar)
- Dark theme (Discord/Spotify стиль)
- System tray + minimize to tray
- Portable build — один .exe без установки
- Страница логов для отладки

## Сценарии использования

### 1. Бизнес-совещания и стендапы
Записывайте ежедневные стендапы, планирования и ретроспективы в Teams или Zoom. После совещания получите структурированный протокол с именами участников и таймстемпами. Больше не нужно назначать ответственного за ведение заметок.

### 2. Интервью и собеседования
HR-специалисты и рекрутеры могут записывать собеседования и получать полный текстовый протокол. Удобно для сравнения кандидатов и документирования ответов. Конфиденциальные данные остаются локально.

### 3. Лекции и образовательный контент
Студенты и преподаватели могут транскрибировать онлайн-лекции, вебинары и образовательные видео. Поддержка мультиязычности позволяет работать с материалами на разных языках. Экспорт в SRT создаёт готовые субтитры.

### 4. Юридическая документация
Адвокаты и юристы могут документировать консультации, показания и переговоры. Полностью локальная работа гарантирует конфиденциальность. Таймстемпы и идентификация спикеров обеспечивают юридическую точность.

### 5. Медицинские консультации
Врачи могут записывать приёмы и консультации для ведения медицинской документации. Данные пациентов не покидают рабочую станцию. Мультиязычность помогает при работе с иноязычными пациентами.

### 6. Контент-создание (подкасты, видео)
Создатели контента могут автоматически получать транскрипцию подкастов и видеороликов. SRT-экспорт генерирует субтитры для YouTube и других платформ. Диаризация разделяет реплики ведущих и гостей.

## Системные требования

### Минимальные
- **ОС:** Windows 10/11 (x64)
- **CPU:** 4 ядра
- **RAM:** 8 GB
- **Диск:** 5 GB (приложение + ML модели)
- **GPU:** Не требуется (CPU-режим: faster-whisper small + int8)

### Рекомендуемые
- **CPU:** 6+ ядер
- **RAM:** 16 GB
- **GPU:** NVIDIA RTX 3060+ (6 GB VRAM) для ускорения транскрипции
- **CUDA:** 12.x

### Скорость обработки (batch-транскрипция)

| Модель | 10 мин аудио (CPU) | 30 мин (CPU) | 10 мин (GPU) |
|--------|-------------------|-------------|-------------|
| small + greedy | ~1.5 мин | ~4.5 мин | ~10 сек |
| small + beam=5 | ~3 мин | ~9 мин | ~20 сек |
| medium + beam=5 | ~6 мин | ~18 мин | ~30 сек |
